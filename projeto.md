# 🎧 DJ BETOBRIZZ — DJ & VJ
## Especificação Completa do Projeto Web

**Projeto:** Website oficial DJ BetoBrizz  
**Categoria:** Portfólio / Divulgação / Landing Page  
**Profissional:** DJ BetoBrizz — DJ & VJ  
**Região:** Mogi Guaçu / Mogi Mirim — SP  
**Objetivo:** Divulgação profissional, apresentação do trabalho, geração de contatos e contratação para eventos.

---

# 1. VISÃO DO PROJETO

O site do **DJ BetoBrizz** deve funcionar como uma experiência audiovisual e não simplesmente como um site institucional.

A primeira impressão precisa transmitir imediatamente:

> **Música + Nostalgia + Energia + Tecnologia + Vídeo + Festa**

O visitante deve sentir que está entrando em uma pista de dança.

A identidade visual deverá combinar:

- Flashback
- Disco
- Música eletrônica
- Neon
- Laser
- VJ
- Telões
- Clubs
- Anos 80/90/2000
- Tecnologia
- DJ profissional
- Eventos
- Vídeo
- Energia

O site deverá ser extremamente visual, moderno e responsivo.

---

# 2. OBJETIVOS

## Objetivos principais

1. Apresentar o DJ BetoBrizz.
2. Mostrar experiência como DJ e VJ.
3. Divulgar eventos realizados.
4. Exibir fotos e vídeos.
5. Divulgar sets musicais.
6. Apresentar estilos musicais.
7. Facilitar contratação.
8. Facilitar contato via WhatsApp.
9. Direcionar visitantes para Instagram e Facebook.
10. Criar uma presença digital profissional.

## Objetivo comercial

O visitante precisa conseguir entrar no site e, em poucos segundos, entender:

- Quem é o DJ.
- O que ele faz.
- Que tipo de evento atende.
- Como é sua apresentação.
- Que tipo de música toca.
- Que tipo de estrutura utiliza.
- Como contratar.

# 63. DIRETRIZ PRINCIPAL PARA A IA/DEV

O desenvolvedor não deve interpretar este projeto como:

> "um site simples para DJ."

Deve interpretar como:

> **"Uma experiência digital que representa uma apresentação de DJ + VJ."**

O visitante deve sentir:

```text
ENTREI NO SITE
        ↓
VI O DJ
        ↓
VI A ENERGIA
        ↓
VI OS VÍDEOS
        ↓
OUVI OS SETS
        ↓
ENTENDI O TRABALHO
        ↓
QUERO CONTRATAR
        ↓
WHATSAPP
```
